# ADB Manager

Hecaton용 Android Debug Bridge GUI 플러그인입니다. 단말 연결·해제, 무선 디버깅, adb 서버 재시작, 실시간 logcat, 패키지·파일·포트 포워딩 관리, 셸 명령을 CLI 단축키 암기 없이 클릭과 메뉴로 다룹니다. Hecaton API 1.13 이상을 사용합니다.

## 화면 구성

```
 ADB 36.0.0 [단말 2대]               [ 새로고침 ] [ 연결… ] [ 페어링… ] [ 서버 재시작 ] [ 서버 종료 ]
──────────────────────────┬────────────────────────────────────────────────────────────────
 단말 (2) ──────────────  │  개요 │ Logcat │ 패키지 │ 파일 │ 셸 │ 포워딩          ● SM F956N
 ● SM F956N            U  │────────────────────────────────────────────────────────────────
 ● SM F956N            W  │ 단말 정보 ─────────────────────────────────────────────────────
                          │ 모델        samsung SM-F956N        배터리   ██████░░ 87% ⚡
 무선 ────────────────── │ ...
 ◐ 192.168.0.44:40123     │ 작업 ─────────────────────────────────────────────────────────
                          │ [ 스크린샷 ] [ APK 설치… ] [ 재부팅 ▾ ] [ Wi‑Fi 디버깅 ] ...
 [ 연결 ] [ 페어링 ] [ 탐색 ]
 ✓ SM F956N 온라인
 [Tab] 탭  [[ ]] 단말  [s] 스크린샷  [i] 설치  [w] Wi‑Fi  [R] 재부팅  [r] 새로고침  [?] 도움말
```

- **왼쪽 사이드바**: 연결된 단말 목록(U=USB, W=무선, E=에뮬레이터)과 상태 배지. 클릭으로 작업 대상을 고릅니다. mDNS로 발견한 무선 디버깅 단말은 `무선` 섹션에 나타나며 클릭 한 번으로 연결·페어링합니다. 폭이 72열 미만이면 사이드바가 접히고 제목 줄의 `단말: ▾` 드롭다운으로 대체됩니다.
- **제목 줄 툴바**: 새로고침, TCP/IP 연결, 페어링, 서버 재시작(`kill-server` + `start-server`), 서버 종료.
- **탭**: 선택한 단말에 대한 여섯 가지 작업 화면.
- **하단**: 상태 줄(결과·진행·hover 설명)과 클릭 가능한 단축키 바.

모든 컨트롤은 마우스로 조작할 수 있고 hover 시 배경이 바뀌며 툴팁이 뜹니다. 어디서든 우클릭하면 그 자리에 맞는 컨텍스트 메뉴가 열립니다. 파괴적 작업(서버 종료, 재부팅, 제거, 데이터 삭제, 파일 삭제)은 확인 다이얼로그를 거치며 기본 버튼은 항상 취소입니다.

## 탭별 기능

| 탭 | 기능 |
| --- | --- |
| 개요 | 모델·Android 버전·빌드·보안 패치·시리얼·ABI·해상도·Wi‑Fi IP·가동 시간·메모리·저장소·배터리. 스크린샷 저장, APK 설치, 재부팅(시스템/리커버리/부트로더/fastbootd/사이드로드/전원 끄기), Wi‑Fi 디버깅 원클릭(`tcpip 5555` → IP 로 `connect`), tcpip 포트 지정, USB 모드 복귀, TCP 연결 해제, 파일 push/pull, 대화형 셸 탭 열기, 텍스트 입력, 키 이벤트(HOME/BACK/POWER…), 시리얼 복사 |
| Logcat | `adb logcat -v threadtime` 실시간 스트리밍(최근 5,000줄 유지). 레벨별 색상, 최소 레벨·텍스트·태그·PID(패키지 이름으로도 지정) 필터, 태그 숨기기, 따라가기/일시정지와 `새 줄 N` 배지, 버퍼(main/system/crash/…) 선택, 단말 버퍼 비우기, 파일 저장(필터된 줄 또는 전체). 줄 우클릭 → 복사, 이 태그만, 이 태그 숨기기, 이 PID만 |
| 패키지 | 서드파티/전체 목록, 이름 검색, 항목 우클릭 또는 Enter → 실행, 강제 종료, 이 앱의 Logcat, 앱 정보, APK 가져오기, 이름 복사, 데이터 삭제, 제거 |
| 파일 | 단말 파일 탐색(경로 브레드크럼, 상위, 경로 이동), 폴더 열기, pull, 이 폴더로 push, 새 폴더, 삭제, 경로 복사 |
| 셸 | `adb shell` 명령을 다이얼로그로 입력하고 결과를 패널에 누적. 빠른 명령(getprop, dumpsys battery, top, df 등), 마지막 명령 반복, 이전 명령 우클릭으로 재실행·복사 |
| 포워딩 | `forward`/`reverse` 규칙 목록, 추가(`tcp:8080 tcp:8080` 또는 `8080`), 개별 제거, 전체 제거 |

## 단축키

| 키 | 기능 |
| --- | --- |
| Tab / Shift+Tab, 1–6 | 탭 전환 |
| [ / ], D | 이전/다음 단말, 단말 선택 메뉴 |
| ↑ ↓ PgUp PgDn Home End | 현재 목록 이동 |
| Enter | 현재 항목 작업(패키지 메뉴, 폴더 열기, 셸 명령 입력, 규칙 메뉴) |
| r, b, ?, q | 새로고침, 사이드바 토글, 도움말, 종료 |
| W, P, K, R | 연결…, 페어링…, 서버 종료, 재부팅 메뉴 |
| 개요: s / i / w / t | 스크린샷 / APK 설치 / Wi‑Fi 디버깅 / 셸 탭 |
| Logcat: p / l / / / c / S / x / y / m | 따라가기 / 레벨 순환 / 텍스트 필터 / 지우기 / 저장 / 필터 해제 / 선택 줄 복사 / 줄 메뉴 |
| 패키지: / / a / m / i | 검색 / 전체·서드파티 / 작업 메뉴 / 설치 |
| 파일: Enter → / Backspace ← / g / u / n / Del / m | 열기 / 상위 / 경로 이동 / push / 새 폴더 / 삭제 / 메뉴 |
| 셸: Enter / k / . / c | 실행 / 빠른 명령 / 반복 / 지우기 |
| 포워딩: f / v / Del / m | forward 추가 / reverse 추가 / 제거 / 메뉴 |

Ctrl 또는 Shift 를 1.2초쯤 누르면 Hecaton 단축키 카드에 이 플러그인의 수정자 단축키가 표시됩니다.

## adb 탐색

시작할 때 저장된 경로 → `PATH` 의 `adb` → `ANDROID_HOME`/`ANDROID_SDK_ROOT` → OS별 기본 SDK 위치(Windows `%LOCALAPPDATA%\Android\Sdk\platform-tools`, macOS `~/Library/Android/sdk/platform-tools`, Linux `~/Android/Sdk/platform-tools`) 순으로 `adb version` 을 시험합니다. 찾지 못하면 안내 화면에서 **adb 위치 지정…** 으로 실행 파일을 고를 수 있고, 선택은 설정에 저장됩니다.

## 설정과 권한

- 설정은 `HECA_PLUGIN_DATA_DIR/config.json` 에 저장됩니다: adb 경로, 최근 무선 연결 주소, logcat 최소 레벨·버퍼, 패키지 범위, 사이드바 표시, 마지막 파일 경로·탭. 변경 즉시 저장됩니다.
- 사용하는 권한: `process_exec`(adb 실행), `fs_read`/`fs_write`(설정, 로그 저장), `clipboard_write`(복사), `open_tab`/`terminal_input`(셸 탭). 각 권한의 용도는 `plugin.json` 의 `permission_usage_descriptions` 에 한국어·영어로 적혀 있습니다.
- 단말 목록은 3초(최소화 중 10초)마다 갱신하고, 개요 정보는 30초마다, mDNS 탐색은 20초마다 갱신합니다. 단말이 온라인이 되거나 사라지면 상태 줄에 알립니다.

## 검증

```
node --test tests/adb.test.js tests/ui.test.js
```

`adb.test.js` 는 `devices -l`, `ls -lA`, `forward --list`, `mdns services`, 단말 정보 스크립트, logcat 줄 파서와 필터·버퍼 상한, 설정 검증, 번역 키 누락을 검사합니다. `ui.test.js` 는 가짜 Hecaton 호스트로 플러그인을 부팅해 렌더링, 탭·단말 전환, logcat 스폰과 출력 반영, 버튼 클릭·우클릭 메뉴·확인 다이얼로그, 좁은 창과 한국어 표시, 파일 탐색·셸·포워딩, 최소화 화면을 확인합니다. 실제 adb 는 실행하지 않습니다.
